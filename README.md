# Code Pet

Фоновые компаньоны для PyCharm: развиваются за код и самостоятельно играют, исследуют и занимаются своими вещами. **0.6.0 · PyCharm 2026.3, SDK 263.7307.206 · Java 25.**

## Попробовать

Закрой предыдущий тестовый PyCharm и выполни из корня проекта:

```sh
python3 run_ide.py
```

Открой исходный файл. Панель доступна через **View → Tool Windows → Code Pet** или поиск действий `⌘⇧A`. Скрипт собирает актуальный плагин и использует отдельный профиль `build/sandbox`; основной профиль IDE не затрагивается.

## Несколько питомцев

Создавай спутников и включай **Показывать этого питомца** у каждого нужного профиля. Они появляются одновременно. Стрелки и лента выбирают профиль для настройки, сохраняя присутствие остальных. Последний включённый профиль остаётся включённым; временно скрыть всех позволяет **Не мешай 30 мин**.

24 вида: кот, пёс, лис, кролик, панда, медведь, коала, енот, хомяк, мышь, белка, ёж, сова, пингвин, цыплёнок, дракон, динозавр, черепаха, лягушка, аксолотль, летучая мышь, привидение, робот и слайм. Есть 16 цветов для частей тела и вещей, узоры, глаза, хвосты и четыре слота одежды, включая плащи, очки и джетпак.

В панели три вкладки: **Образ**, **Настройки**, **Прогресс**. Истории и занятия выбираются автоматически. Кормление, выбор действий и ручной сон не нужны. Поглаживание остаётся необязательным общением.

## Игры во время кода

| Действие в основном редакторе | Реакция |
|---|---|
| **Enter** | Мяч вылетает возле каретки и отскакивает от границ видимой области. Питомцы сначала оценивают траекторию, затем бегут и прыгают за ним. |
| **Tab** | У каждого анимированного спутника появляется шарик с верёвкой; порывы ветра уносят его вверх по извилистой траектории. |
| **Delete / Backspace дольше 650 мс** | Питомцы перемещаются в нижний правый угол, увеличиваются и садятся в кресла с попкорном, глядя влево вверх. После отпускания сценка держится ещё 4 секунды. |
| **Run**, в том числе сочетанием клавиш | Питомцы появляются возле верхней кнопки запуска. Один произносит видовое пожелание удачи: по 12 вариантов для каждого вида. |
| Наведение на питомца | Он сжимает глаза; автономное занятие приостанавливается. |

Клавиши продолжают выполнять обычную работу IDE: Enter создаёт строку, Tab делает отступ или выполняет другое назначенное действие, Delete/Backspace удаляет код. Плагин наблюдает события, не потребляет их и не меняет keymap. Игры включаются отдельно в **Настройках**. В консоли и вспомогательных редакторах игровые клавиши не обрабатываются. Модифицированные сочетания пропускаются.

Сила прыжка зависит от вида: кролик и лягушка прыгают выше черепахи и слайма. Надетый **Джетпак** позволяет лететь за мячом. Одновременно существует один общий мяч: новый Enter перезапускает его. Есть ограничения на автоповтор Enter/Tab. Мяч исчезает через 25 секунд; шарик завершает подъём у верхнего края или через 14 секунд.

## Позади текста и в Project

В редакторе питомцы и игрушки рисуются **после фона, перед буквами**, через `CustomHighlighterOrder.AFTER_BACKGROUND`. Они могут заниматься делами прямо во время печати: текст рисуется поверх них. Это рисование, исходник и undo не изменяются. Для игры с символами берётся только визуальная копия буквы.

Часть автономных прогулок проходит в свободном низу **видимой** панели Project. Питомцы появляются там, только если под последней строкой дерева есть хотя бы 125 px свободного места. Скрытая панель не открывается, файлы и строки дерева не перекрываются. Если места нет, используется редактор.

Отключение **Питомцы позади текста кода** убирает их из редактора, включая игры с клавишами; остаются свободный низ Project и пожелания при запуске. Слой окна пропускает мышь и не забирает фокус. В неактивном окне и тихом режиме сцены приостанавливаются.

Положение кнопки Run определяется по видимой подсказке/accessible name. Если конкретная компоновка её не раскрывает, используется область справа сверху. Точное положение в разных интерфейсах PyCharm требует ручной проверки.

## Самостоятельные истории

У каждого вида **12 цепочек**: шесть общих занятий с адаптацией к анатомии и шесть видовых. Всего 288 рецептов из общих действий и эффектов. Например: найти игрушку, потерять, поискать и принести домой; достать метлу, подмести, почистить буквы и убрать инструменты.

Призрак растворяется до одних глаз, робот мастерит шестерёнку, летучая мышь висит вниз головой, черепаха прячется в панцирь. Характер влияет на выбор занятий. Через 45 секунд без мыши и клавиатуры чаще выбирается уборка; примерно в 28% завершённых историй выбирается возможность плавного увеличения до 1,6 раза во время отсутствия. Возвращение к работе возвращает обычный размер. Истории доигрывают последовательность без прежнего лимита 2,6 секунды; игровые события могут их временно прерывать.

[Каталог историй](docs/STORIES.md). Во вкладке **Прогресс** находятся уголок и находки за уровни 2–7. Новая одежда открывается в гардеробе, выбранный образ сам не заменяется. Иногда питомцы произносят короткие реплики. Распознанные pytest/unittest/JUnit-конфигурации вызывают косметическую реакцию по коду завершения; это не анализ дерева результатов тестов.

## Прокачка и сохранение

- **+2 XP** за новую учитываемую строку с более чем 10 непробельными символами.
- **+5 XP** за каждые 100 новых непробельных символов, с сохранением остатка.
- Каждый включённый питомец получает полный XP за подходящие правки; это не деление награды между ними. Состав получателей фиксируется до batch правок. Пауза XP действует на отдельный профиль.
- Новый исходный файл вызывает перекус у включённых питомцев, без XP.
- Следующий уровень стоит `100 × текущий уровень`; накопленный XP не тратится.
- Игры, время, истории, поглаживания и реакции на запуск не дают XP.

Общие максимумы файла предотвращают повторную награду за удаление и ввод того же объёма, смену профиля и перезапуск. Уже существующий код становится исходной точкой. Учитывается прирост объёма, а не качество кода. Отдельные комментарии по префиксам и пробелы исключаются; полного парсера нет. Обработка выполняется после паузы во вводе около 650 мс. Служебные/генерируемые папки, undo/redo, консоль, внешние изменения и документы >500 000 UTF-16 единиц исключаются.

Профили, включённые спутники, выбранный для настройки профиль, XP, одежда, находки и настройки сохраняются в `options/code-pet.xml` через штатное сохранение IDE. Есть миграция старых версий. Кадры, текущие игрушки, удерживаемые клавиши и позиции мыши на диск не пишутся.

## Отправить и проверить

```sh
python3 scripts/publish.py
```

Команда из обычного терминала ноутбука проверяет ветку `main` и SSH origin `Dlzxn/code-pet`, добавляет исходники, создаёт коммит при изменениях и выполняет обычный push. Force push и локального запуска тестов нет. Push запускает [GitHub Actions](https://github.com/Dlzxn/code-pet/actions), где выполняются тесты и упаковка. При расхождении истории push остановится для обычного разрешения конфликта.

```sh
python3 scripts/check.py                 # полный набор, также используется в CI
python3 tests/run.py --compile-only       # только сборка Java и классов тестов
python3 build.py                          # только плагин
```

Архив: **dist/code-pet-0.6.0.zip**. Установить можно через **Plugins → Install Plugin from Disk**, без распаковки. SDK задаётся через `PYCHARM_HOME`; сборка использует локальный SDK. CI устанавливает точный Linux SDK с проверкой SHA256 и отдаёт ZIP/отчёты.

**Для 0.6 выполнена компиляция, новые тесты подготовлены для CI.** Headless-проверки не подтверждают настоящее окно IDE, порядок рисования всех inlay/folding/selection, Retina и положение Run. Нужна [ручная приёмка](docs/TESTING.md). [Архитектура](docs/ARCHITECTURE.md) · [CI/CD](docs/CI.md) · [Изменения](CHANGELOG.md).
