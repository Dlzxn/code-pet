# Проверка Code Pet

## Один вход для локальной разработки и CI

```sh
python3 scripts/check.py
```

Успех возвращает код 0. Первая ошибка останавливает команду с ненулевым кодом. Логи и JSON-итог находятся в `build/reports`. Большое число Java assertions включает матрицу кадров; это не число независимых интеграционных сценариев и не процент покрытия.

| Область | Автоматически | Обязательно вручную |
|---|---|---|
| XP | Порог 100 символов, >10 символов, суммы, остаток, пауза, переполнение, 200 границ уровней | Реальный ввод и события команд редактора |
| Файлы | Метрики, фильтры путей, максимумы, отсутствие повторной награды | Создать файл через New File, исключённые папки, отсутствие перекуса при refresh |
| Коллекция | Создание, независимый XP, круговое переключение, повреждённые ID | Несколько проектов и окон |
| Сохранение | Настоящий XML-сериализатор SDK, запись/чтение файла, миграция 0.1/0.2, снимок состояния | Штатное автосохранение IDE и перезапуск |
| Поведение | Достижимость 36 состояний, последовательность исчезновение→закулисье→появление, границы, пауза и наведение | Плавность и уместность сцен |
| Рисунок | 24 вида × 36 сцен × 3 момента, все слоты аксессуаров и цвета, изменение глаз при hover | Темы IDE, Retina и масштабирование |
| Размещение | Пустые/занятые/маленькие области и случайные прямоугольники препятствий | Soft wrap, folding, inlay hints, split editor, прокрутка |
| UI | Реальные кнопки карусели/создания/взаимодействий/имени, отрисовка вкладок | Клавиатура, прокрутка, узкая панель и доступность |
| SDK-сервисы | Адаптеры SDK: batch, discard, владелец XP и остановка таймера | Жизненный цикл реальных окон и проектов |
| Дистрибутив | ZIP/JAR, ссылки классов из XML, версия, отсутствие тестов/личных данных | Установка через Plugins и IDE Log |
| CI-инструменты | Макеты SDK macOS/Linux, проверка checksum, кеш, неправильная версия | Настоящая загрузка SDK и GitHub Actions |

SDK-адаптеры используют контролируемые Application/Project/Document. Они не поднимают полноценный IntelliJ Platform и не заменяют Plugin Verifier или тестовую IDE. Сторонний инструмент покрытия и Plugin Verifier пока не подключены.

## Ручная приёмка

Запусти `python3 run_ide.py` из обычного терминала macOS. Перед обновлением закрой прежнюю тестовую IDE.

1. Проверь загруженную версию 0.3.0 в Plugins и отсутствие ошибок `dev.codepet` в IDE Log.
2. Не открывая панель, открой исходный файл с небольшим количеством строк. Питомец появляется в пустой области и самостоятельно меняет занятия. Появление/исчезновение должны иметь переходы.
3. Наведи мышь на питомца: глаза жмурятся, движение приостанавливается; щелчок и колесо продолжают работать в редакторе. Он не должен забирать фокус.
4. Добавь код возле питомца, прокрути, включи soft wrap, сверни блок, добавь inlay hints, смени вкладку и split. Рисунок не должен перекрывать текст или каретку. Если место занято — должен исчезнуть.
5. Открой длинный файл в узком окне, заполни экран кодом: скрытие нормально, вторжение в текст — ошибка. Проверь масштаб UI и редактора, Retina и внешний монитор.
6. На новом пустом `.py` файле введи `value = 1234567890`, подожди >650 мс: +2 XP за одну подходящую строку. При достижении 100 непробельных символов добавляются +5 XP. Считай без пробелов и строк комментариев.
7. Удали и введи прежний объём: повторной награды нет. Переключи питомца и повтори: общий максимум файла не сбрасывается. Новые строки/объём сверх максимума начисляются активному питомцу.
8. Проверь undo/redo, терминал, консоль, bulk-форматирование, фоновые изменения и `build`/`.idea` внутри проекта. При неоднозначном событии отмена ожидающего batch допустима.
9. Создай новый файл через меню IDE: питомец автоматически ест. XP за создание не добавляется. Открытие старого файла и внешний refresh не должны запускать массовые перекусы.
10. В панели создай по питомцу нескольких видов; используй стрелки. Активен один. Проверь все четыре вкладки, цвета частей и сочетания аксессуаров, имя, масштаб и характер. Игры и поглаживания XP не дают.
11. Отключи реплики, движение и прогулки по отдельности. Код должен давать XP, пока не включена пауза XP. Пауза не копит награду для выдачи после снятия.
12. Перезапусти IDE: коллекция, выбранный питомец, образы, XP, остатки символов и максимумы файлов восстановлены. Проверь миграцию на копии старого сохранения; основной профиль не использовать для экспериментов с повреждёнными XML.
13. Открой второй проект/окно и вернись обратно. Показывается один активный персонаж в активном окне, XP не дублируется. Закрой проект/IDE: лишних рисунков и таймеров нет.

## Как описывать ошибку

Укажи версию ZIP и build PyCharm, действие, ожидаемое и фактическое поведение. Приложи скриншот и относящиеся к Code Pet строки IDE Log. Не публикуй весь профиль IDE или сохранения с личными именами/путями без просмотра. Для визуальной ошибки добавь тему, UI scale, editor zoom и наличие soft wrap/inlay hints.
