# Каталог историй 0.6

У каждого вида 12 цепочек: шесть общих историй с собственной анатомией и шесть видовых с особыми предметами и эффектами. Действия переиспользуются между историями; это не 288 независимо нарисованных мультфильмов. Все сцены косметические, без изменения исходного текста и без XP.

## Кот

- **Подмести дорожку**: Достаёт метлу → Подметает пиксели → Смахивает пыль с букв → Убирает вещи на полку.
- **Помыть буквы**: Несёт ведёрко → Моет буквы → Полирует символы → Убирает вещи на полку.
- **Потерянная игрушка**: Вылезает из коробки → Играет с мячом → Ищет потерянную игрушку → Нашёл игрушку! → Возвращается в уголок.
- **Пикник с уборкой**: Устроил пикник → Перекусывает → Моет буквы → Складывает плед → Возвращается в уголок.
- **Мастерская скобок**: Поднимает букву → Строит башню → Мастерит находку → Показывает находку → Возвращается в уголок.
- **Вещи на место**: Примеряет свой плащ → Протирает очки → Убирает вещи на полку → Возвращается в уголок.
- **Клубок под скобкой**: Следит за искоркой → Занимается любимым делом → Занимается любимым делом → Показывает находку.
- **Лазерный зайчик**: Нюхает цветок → Занимается любимым делом → Играет с мячом → Возвращается в уголок.
- **Охота на точку**: Выглядывает из-под буквы → Занимается любимым делом → Прыгает по символам → Занимается любимым делом.
- **Коробка с секретом**: Ищет потерянную игрушку → Занимается любимым делом → Нашёл игрушку! → Показывает находку.
- **Усы в пене**: Потягивается → Занимается любимым делом → Пьёт чай → Занимается любимым делом.
- **Добыча на полку**: Показывает находку → Занимается любимым делом → Убирает вещи на полку → Возвращается в уголок.
